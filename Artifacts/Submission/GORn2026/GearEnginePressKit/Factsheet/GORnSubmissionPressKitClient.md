# Gear Engine — GO!RN 2026 Submission Press Kit

## Submission Snapshot

**Public working title:** Gear Engine  
**Format:** playable portrait game demo  
**Genre:** tactical racing, mechanical composition, roguelike progression  
**Platform package:** WebGL evaluation build  
**Development status:** active prototype with a reproducible complete gameplay loop  
**Event:** PONG — Mostra de Jogos GO!RN 2026, September 18–19, 2026

Gear Engine is a tactical racing game where the player constructs a gear-driven machine, observes its consequences during a race, earns a result, chooses a roguelike upgrade, and returns to the workshop to improve the next run.

> The public title and identity remain provisional until naming and legal clearance are complete. No launch date, studio identity, CNPJ, traction, commercial performance, or funding claim is asserted in this kit.

## Verified Core Loop

**Configure → race → observe cause and effect → earn → choose an upgrade → reconfigure.**

The current recorded build visibly supports track selection, loadout construction, three race layouts, live race feedback, results, reward selection, storage, and item detail. A fresh downloadable WebGL package is supplied separately for event evaluation.

## Product Positioning

Gear Engine occupies the space between a mobile racer and a systems-building game. The player does not only tune a list of vehicle statistics: they compose a mechanical system whose placement and relationships influence what happens on the track.

**Short promise:** engineer the chain; own the race.

**Audience:** mobile players who enjoy optimization, deckbuilding or roguelike choice, readable systems, short-session progression, and stylized racing.

## Key Features

- Mechanical loadout construction based on gears and relationships.
- Multiple track shapes that expose different configuration consequences.
- Short races with visible performance feedback.
- Result and reward states that close each run.
- Roguelike upgrade choices that change the next configuration cycle.
- Portrait-first presentation with high-contrast pop-art racing direction.

## Usage Guidance

- Untouched files in `Screenshots` and `Video` may be described as current recorded-build gameplay.
- Do not crop away interface context when using a screenshot to prove functionality.
- Do not describe generated route boards or provisional marks as final production art.
- Do not infer launch timing, monetization, traction, team size, company registration, or platform certification.
- For an event listing, use: **“Gear Engine is a tactical racing prototype where players build a gear-driven system, race it, choose upgrades, and refine the next run.”**

## Evaluation Instructions

1. Download and extract the supplied `GearEngineWebGLDemo.zip` archive.
2. Open `StartHere.html` and follow the operating-system instructions.
3. Start the included local web server script, then open the displayed local URL in Chrome, Edge, Firefox, or Safari.
4. Use the game in portrait orientation or a tall browser window.
5. Begin from the main flow, configure the available gear system, start a race, review the result, select a reward, and return to storage.

The build is intended for evaluation and exhibition preparation. Event-machine specifications have not yet been supplied, so final compatibility verification remains pending.
