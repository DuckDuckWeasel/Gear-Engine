# Execution Matrix Scene

`Test Tutorial Scene` contains an `Execution Matrix` hierarchy generated by
`ExecutionMatrixSceneBuilder`. Each child GameObject owns one Blackboard and one Block.

The generated matrix covers:

- Sequence and Selector with Ordered, Random, and Shuffle order.
- Parallel and Parallel Selector with Wait All, Wait Any, and Wait None await behavior.
- Utility Selector with command utilities of 10, 20, and 30.

Each Block contains three standalone actions: Debug Log, Wait, and Debug Log. Messages
include the execution case name so Play Mode behavior can be distinguished in the Console.

Use `GearEngine > Testing > Generate Execution Matrix Scene` to replace the generated
`Execution Matrix` hierarchy deterministically without changing other scene objects.
