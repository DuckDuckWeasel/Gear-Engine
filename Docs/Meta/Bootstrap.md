# Meta scene bootstrap (AppFlow)

The [Meta scene](../../Assets/GearEngine/Scenes/Meta.unity) uses **[`MetaApplicationBootstrap`](../../Assets/GearEngine/Scripts/App/Bootstrap/MetaApplicationBootstrap.cs)** (`Game.App.Bootstrap`), which subclasses **[`GearAppFlowRoot`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/FoundationLayer.cs)** (which subclasses [`AppFlowRoot`](https://github.com/MgCohen/Scaffold/blob/main/Packages/com.scaffold.appflow/Runtime/AppFlowRoot.cs) from `Scaffold.AppFlow`). [`GearAppFlowRoot`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/FoundationLayer.cs) always pushes foundation first, then whatever [`GetGameLayers()`](../../Assets/GearEngine/Scripts/App/Bootstrap/MetaApplicationBootstrap.cs) yields. Layers are pushed in order:

1. **[`FoundationLayer`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/FoundationLayer.cs)** — Registers `IAddressablesAssetClient`, `IAddressablesGateway`, `NavigationSettings`, navigation, no-op view-controller injector, events, and **Addressable catalog publishers** from rebaked [`AddressableScriptableObjectPublisherSO`](../../Assets/GearEngine/Scripts/App/Bootstrap/Publishers/DataDriven/AddressableScriptableObjectPublisherSO.cs) assets assigned on the bootstrap (`addressableCatalogPublishers` on [`GearAppFlowRoot`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/FoundationLayer.cs)). Each publisher derives from [`AssetPublisherBase<T>`](https://github.com/MgCohen/Scaffold/blob/main/Packages/com.scaffold.appflow/Runtime/AssetPublisherBase.cs) (via [`DataDrivenAddressableScriptableObjectPublisher<T>`](../../Assets/GearEngine/Scripts/App/Bootstrap/Publishers/DataDriven/DataDrivenAddressableScriptableObjectPublisher.cs)) and pushes loaded `ScriptableObject` catalogs into descendant layers via `ILayerPublisher`.
2. **[`UgsLayer`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/UgsLayer.cs)** — Installs only `UgsInstaller`. Its `IAsyncInitializable` calls `UnityServices.InitializeAsync()` and signs the player in. This **must** be its own layer because `CloudCodeInstaller.Install` synchronously dereferences `Unity.Services.CloudCode.CloudCodeService.Instance`, which is `null` until UGS finishes initializing — and `IAsyncInitializable.InitializeAsync` only runs after the layer's container is built.
3. **[`LiveOpsLayer`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/LiveOpsLayer.cs)** — Installs `CloudCodeInstaller` and `LiveOpsInstaller` only. [`SequentialInLayerScheduler`](../../Assets/GearEngine/Scripts/App/Bootstrap/SequentialInLayerScheduler.cs) keeps the in-layer `IAsyncInitializable` order deterministic so `LiveOpsService.InitializeAsync` (`GameApi/Sync`) runs in the expected slot.

After all three layers initialize, **`OnReadyAsync`** resolves [`ILiveOpsService`](https://github.com/MgCohen/Scaffold/blob/main/Packages/com.scaffold.liveops/Runtime/ILiveOpsService.cs) and logs the presence of module payloads (e.g. `CurrencyGameData`, `TrackGameData`). Meta does **not** install client modules; that lives in `CampaignLayer` (Main scene).

## Adding a new layer

1. Implement [`IScopeLayer`](https://github.com/MgCohen/Scaffold/blob/main/Packages/com.scaffold.appflow/Runtime/Contracts/IScopeLayer.cs). Keep `Install` to a list of `new SomeInstaller().Install(builder)` calls.
2. To make an Addressables-backed `ScriptableObject` available to **descendant** layers, add a rebaked [`AddressableScriptableObjectPublisherSO`](../../Assets/GearEngine/Scripts/App/Bootstrap/Publishers/DataDriven/AddressableScriptableObjectPublisherSO.cs) to the bootstrap’s **Addressable catalog publishers** list (registered in [`FoundationLayer`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/FoundationLayer.cs)). That registers [`DataDrivenAddressableScriptableObjectPublisher<T>`](../../Assets/GearEngine/Scripts/App/Bootstrap/Publishers/DataDriven/DataDrivenAddressableScriptableObjectPublisher.cs) as `IAsyncInitializable`. Publish-to-descendants is a strict rule: the layer that publishes cannot consume.
3. Yield the layer from `GetGameLayers()` on your [`GearAppFlowRoot`](../../Assets/GearEngine/Scripts/App/Bootstrap/Layers/FoundationLayer.cs) subclass (foundation is always prepended by the base class); the host pushes layers sequentially and finishes one layer's init wave before starting the next.
